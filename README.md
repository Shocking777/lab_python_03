# Лабораторная работа №3 — Каталог медиаобъектов

## Описание проекта

Проект представляет собой каталог медиаобъектов, реализованный на языке Python с использованием объектно-ориентированного программирования.

Программа позволяет добавлять, удалять, искать и хранить медиаобъекты. Для хранения данных используется словарь, обеспечивающий быстрый доступ к объектам по уникальному идентификатору.

Реализованы проверка корректности данных, обработка исключений и сохранение каталога в формате JSON.

## Класс MediaItem

Класс `MediaItem` реализован с помощью декоратора `@dataclass(frozen=True)`.

Каждый медиаобъект содержит следующие атрибуты:

| Атрибут | Тип | Описание |
|---|---|---|
| `id` | `str` | Уникальный идентификатор |
| `name` | `str` | Название |
| `category` | `str` | Категория |
| `year` | `int` | Год выпуска |
| `director` | `str` | Режиссёр |
| `views` | `int` | Количество просмотров |

Метод `__post_init__()` проверяет корректность данных при создании объекта. Строковые поля не должны быть пустыми, год выпуска должен быть не меньше `MIN_YEAR`, а значения должны соответствовать установленным типам.

Использование `frozen=True` запрещает обычное изменение атрибутов после создания объекта.

## Класс Catalog

Класс `Catalog` предоставляет следующие методы:

| Метод | Назначение |
|---|---|
| `add(item)` | Добавление медиаобъекта |
| `get(id)` | Получение объекта по ID |
| `remove(id)` | Удаление объекта |
| `find_by_category(category)` | Поиск по категории |
| `find_by_name(name)` | Поиск по названию без учёта регистра |
| `readonly_view()` | Получение представления только для чтения |
| `save()` | Сохранение каталога в JSON |
| `load(file)` | Загрузка каталога из JSON |
| `__len__()` | Получение количества объектов |
| `__iter__()` | Перебор объектов в порядке добавления |
| `__contains__(item_id)` | Проверка наличия ID в каталоге |

Основное хранилище реализовано с помощью словаря `_items`.

## Дополнительные задания

### 1. Индекс по категориям (+3 балла)

Реализован дополнительный словарь `_category_index`, содержащий категории и соответствующие им идентификаторы объектов.

Индекс позволяет выполнять поиск по категории без полного перебора каталога.

При добавлении, удалении и загрузке объектов индекс обновляется вместе с основным хранилищем.

### 2. Read-only view (+2 балла)

Для предоставления доступа к каталогу только для чтения используется `MappingProxyType`.

Метод `readonly_view()` позволяет просматривать элементы каталога, но запрещает изменять состав словаря через полученное представление.

Дополнительно `MediaItem` использует `frozen=True` для защиты атрибутов объектов от обычного присваивания.

## Обработка исключений

В проекте реализована собственная иерархия исключений:

- `CatalogError` — базовое исключение.
- `InvalidItemError` — некорректные данные медиаобъекта.
- `DuplicateIDError` — дублирование идентификатора.
- `ItemNotFoundError` — объект не найден.
- `UnsupportedVersionError` — неподдерживаемая версия JSON.
- `CorruptedFileError` — некорректный JSON или неверная структура данных.

## Сохранение и загрузка JSON

Каталог сохраняется в файл `catalog.json`.

Пример структуры:

```json
{
    "format_version": 1,
    "items": [
        {
            "id": "001",
            "name": "Marvel",
            "category": "Action",
            "year": 2026,
            "director": "Tarantino",
            "views": 1234
        }
    ]
}
```

Перед загрузкой проверяются версия формата, структура файла и корректность медиаобъектов.

Для предотвращения частичных изменений данные сначала загружаются во временный каталог. Основной каталог обновляется только после успешной проверки всех записей.

## Установка и запуск

### 1. Создание виртуального окружения

```bash
python3 -m venv .venv
```

Активация на macOS/Linux:

```bash
source .venv/bin/activate
```

### 2. Установка инструментов

```bash
python3 -m pip install pytest mypy ruff
```

Основная программа использует стандартную библиотеку Python и не требует дополнительных зависимостей.

### 3. Запуск программы

```bash
python3 main.py
```

## Тестирование

Для проверки программы используется pytest.

Запуск всех тестов:

```bash
pytest -v
```

Тесты охватывают создание и валидацию медиаобъектов, добавление, получение и удаление элементов, проверку дублирующихся ID, поиск, порядок итерации, сохранение и загрузку JSON, обработку ошибок и отсутствие частичных изменений при неудачной загрузке.

### Проверка качества кода

Проверка Ruff:

```bash
ruff check .
```

Проверка типов mypy:

```bash
mypy .
```
